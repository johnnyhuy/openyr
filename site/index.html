04 DOWNLOAD & DEPLOY ENGINE ONLY

OPENYR SOURCE

The current engine source, ready to build with mise.

DOWNLOAD .ZIP

No prebuilt application release is published yet. Build a native macOS app from source using the orders below. Check GitHub releases for future application packages.

  1. PREPARE YOUR GAME DATA

    You need a legally owned Red Alert 2 + Yuri's Revenge install. Keep the folder containing ra2.mix and ra2md.mix. OpenYR does not include the game.

  2. INSTALL THE PROJECT TOOLS

    Install mise and Git, then open a terminal in the downloaded source folder.

    mise trust
mise install
mise run package
open target/OpenYR.app

  3. CHOOSE YOUR INSTALL & COMMAND A SKIRMISH

    On macOS, select your game-data folder when prompted. Open Single Player, choose Skirmish and set up your battle.

macOS packaging instructions are for local source builds. Linux contributors also need a desktop display, pkg-config and ALSA development headers. Full build instructions / macOS packaging notes.
